# Archive - KeyGo Server

Documentacion historica, superseded o de investigacion.

## Uso

- No usar esta carpeta como fuente de verdad operativa por defecto.
- Si un documento activo apunta aqui, debe hacerlo explicitamente como referencia historica.
- Cuando un plan o documento deja de ser canonico pero conviene conservarlo, se mueve o se replica aqui.

## Subcategorias

- `research/`: investigaciones y deep dives historicos.
- `plans/`: planes ejecutados o reemplazados.
