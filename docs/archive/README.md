# Archive - KeyGo Server

Documentación histórica, superseded o de investigación.

## Uso

- No usar esta carpeta como fuente de verdad operativa por defecto.
- Si un documento activo apunta aquí, debe hacerlo explícitamente como referencia histórica.
- Cuando un plan o documento deja de ser canónico pero conviene conservarlo, se mueve o se replica aquí.

## Subcategorias

- `research/`: investigaciones y deep dives históricos.
- `plans/`: planes ejecutados o reemplazados.
